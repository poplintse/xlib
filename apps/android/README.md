# Android 阅读交互

## 批量新增书籍

- 系统文件选择器允许多选 TXT，单次最多 20 本，单本导入仍可使用。
- 系统文件选择器没有统一的最大多选数参数；应用在接收结果时校验，超过 20 项整批拒绝，不偷偷截取前 20 本。
- 取消选择不导入；兼容单 URI 和多项 ClipData，同一批次重复 URI 只导入一次。
- 导入发布前按文件大小及完整字节内容判重，覆盖已有书架、本批次及排队批次中已准备成功但尚未显示的文件。分块读取，不把整本书装入内存，不只比较名称或文件开头。
- 同内容不同名称跳过；同名不同内容允许新增。不同编码、BOM 或换行导致字节不同的文件不视为重复，不做有损正文归一化。
- 重复项显示“书籍已存在，已跳过”，不启用占位卡片，不覆盖已有书籍、进度、书签或目录；仅清理本次导入的临时副本。结果分别统计新增、重复、失败。删除已有书籍后允许重新导入。
- 选择结束后立即在书架显示本批占位卡片，名称在后台读取；“等待导入”和“正在导入”状态均置灰、禁用，不提供打开、编辑、删除或管理勾选入口。
- 文件复制与编码检测在后台串行执行，一本失败不阻止后续文件；每本成功后立即保存并替换为可阅读卡片，不等待整批完成。失败卡片不启用，批次结束后移除并在结果中提示。
- 批次结束后移除临时占位卡片，并显示新增、重复与失败数量；不打断正在阅读的书籍。
- 每本书使用独立 ID 和临时文件，防止短时间批量导入造成 ID 冲突；失败时清理本次临时副本，不修改或删除源文件。
- 不上传书籍，不增加存储权限。Activity 销毁时停止后续导入；已经成功发布的书籍保留，等待/导入中占位状态不持久化为正式书籍。
- 验收覆盖单本、20 本、超限、取消、重复 URI、同名书籍和部分文件不可读取。

## 搜索范围

- 搜索页不显示“书内搜索”标题和书名，顶部直接显示返回、搜索输入框和搜索按钮。
- 输入框下方提供“从当前页面往后 / 从头开始”两个互斥选项。每次从正式阅读页进入时默认前者；从结果临时阅读返回时保留选择。
- “从当前页面往后”从当前阅读页起始字节 offset 搜到文件末尾；“从头开始”从 offset 0 搜索整本书。
- 切换范围清空旧结果并使旧异步回调失效，保留输入关键词，点击搜索或键盘搜索键后重新执行。
- 原有分批加载和手工“从开头继续搜索”规则保持不变；整本搜索完成后不再提示从开头继续。
- 搜索起点与正式阅读返回位置独立；从头搜索、查看结果都不得把原阅读进度重置到书首。
- 本节为 Android 新增交互要求，替代旧规范中固定只能从当前阅读位置开始搜索的描述；不改变其他客户端。

## 文字选择与复制

- 阅读正文长按选中词语，显示选区高亮、前后两个拖动锚点及应用内“复制 / 取消”浮层，不启动系统 ActionMode/context 菜单。正文关闭原生文本选择和智能分类；邮箱等输入框保持系统编辑行为。
- 拖动任一锚点调整当前页内的范围，支持跨行；不自动翻页或跨页选择。两个端点不能交叉或形成空选区。
- 只有点击“复制”才将原始选中文本写入系统剪贴板；保留换行，不包含书名、页码或阅读 offset。不上传内容，不依赖后端。
- 选择操作复用分页 StaticLayout 坐标，不重新排版，不改变阅读进度。字符选择索引与持久化字节 offset 分离。
- 进入选择时关闭自动翻页；复制或取消后由用户重新开启。拖动锚点不触发翻页、菜单开关或边缘返回。
- 点击正文其他位置只取消选择，不同时翻页；返回键先取消选区，不退出阅读。拖动锚点时隐藏操作浮层，松手后重新定位；页面重新绑定、窗口失焦或离开阅读界面时清除选区。
- 高亮和锚点随正文颜色适配阅读主题；空页面不能选词。

本功能属于 Android 客户端阅读交互，不自动改变其他客户端或同步契约。

### 验证

在 `apps/android` 运行 `./gradlew testDebugUnitTest lintDebug assembleDebug`。

真机验收：长按中文/英文 → 分别拖动两个锚点跨行 → 点击复制 → 粘贴核对原文；
覆盖首尾行、标点、emoji、浅色/深色、自定义字体及行距、自动翻页开启、搜索高亮；
确认取消选区后正常翻页，阅读进度不因选择发生改变；长按前后均不得出现系统文本操作菜单。复制成功后的系统剪贴板通知不属于选择菜单，不屏蔽。厂商独立识屏/辅助服务可能在应用之外拦截手势，须在目标手机单独确认，不能承诺应用能禁用全部系统级识屏。
