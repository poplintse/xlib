# Decision 0008：同一本书同一位置只保留一个书签

状态：accepted，用户于 2026-09-14 明确确认。

## Context

Android 当前按书籍与字节位置去重；iOS 当前每次添加都追加记录，同一位置可以出现多条书签。用户确认采用同位置唯一规则。

## Decision

- 同一本本地书籍、同一原始文件字节 offset，只保留一个书签。
- 已有该位置书签时，再次添加不创建新记录，提示“当前位置已有书签”，保留原书签。
- 唯一性使用本地书籍标识与原始字节位置判断，不使用显示百分比、页码或正文摘要。不同位置即使显示相同百分比，也不合并；不同书籍同一 offset 也不合并。

## Reason

重复点击不应制造没有新增定位价值的重复书签；使用精确位置避免显示舍入导致错误合并。

## Consequences

CAP-BOOKMARK 采用本规则。Android 已覆盖位置唯一及单条删除；iOS 添加路径待调整。单条书签删除由 [Decision 0009](0009-delete-individual-bookmark.md) 确认为共同要求，当前状态见能力矩阵。

实施与验收状态见 [CURRENT](../../CURRENT.md)。历史重复记录的迁移清理不在本次决定范围，后续实施时需说明处理方式，不能据此自动删除用户现有数据。

后续验收应覆盖同位置重复添加、不同 offset 但相同显示百分比、不同书籍同 offset；
