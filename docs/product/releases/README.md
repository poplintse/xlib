# 产品发布记录

仅记录一个实际版本中各客户端发布了哪些 Capability 和 Client-specific Feature，以及实际限制。Release 不得作为产品需求源，也不能把计划中的能力写成已发布。

仓库根 [releases/](../../../releases/) 保持 monorepo 版本、组件与构建清单职责；此目录只补充经核实的业务交付映射，不复制版本元数据。不根据当前工作树反推历史发布内容。

未来有已确认发布时使用稳定版本文件名，记录版本、发布日期、发布依据、各客户端能力 ID、实现范围和专属功能。此次初始化没有核实实际分发证据，故不创建推测性的版本文件。
